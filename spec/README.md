## 1. 产品一句话概述

「校园理财管家」（暂定名，正式发布前可修改）是一款帮助中国大学生汇总与规划理财信息的 Web 网页应用：无账号、数据存于浏览器本地，通过手动录入与支付宝/微信账单 CSV 导入，把分散在微信、支付宝、银行各处的钱统一成一张资产与收支视图。它为理财小白（本金几千元以内、生活费结余、需从零科普）而设计，解决"不知道自己一共有多少钱、钱花去了哪里、想攒钱却没有匹配学期节奏的工具"这一核心问题。首期（P0）覆盖资产汇总与理财规划；股票分析与银行产品信息库为二期（P1）。

## 3. 第一性原理硬约束摘要

五条硬约束及推导出的核心决策（权威定义详见 [01-产品定位与整体方案](01-产品定位与整体方案.md) 第 4 章）：

1. **无开放接口**：主流理财平台不向个人第三方应用开放资产查询接口 → 不做自动同步，采用手动录入 + 账单文件导入。
2. **无券商对接**：无法对接券商实盘交易 → 不接触真实资金，股票模块仅为信息层。
3. **资源有限**：个人小应用资源有限 → 无账号本地优先，数据存浏览器本地，备份责任在用户。
4. **内容涉投资**：全部投资相关内容定位为教育性信息，不构成投资建议，不推荐具体产品。
5. **用户是小白**：目标用户未系统学习过理财 → 概念首次出现附浅白解释，围绕低频查看与快照更新设计，不自造专业门槛。

## 5. 建议阅读顺序

**评审者路径**：01 → 08 → 02 → 03 → 04 → 05 →（二期）06 → 07。先读 01 建立问题、用户与术语基准（全套文档的共享概念以 01 第 5 章为唯一定义处）；随后读 08 掌握数据与合规的横切边界——所有模块都受其约束，提前读可避免在模块细节中反复回查；再按 02→03→04→05 依次评审 P0 模块；二期文档 06、07 在 P0 评审通过后阅读。

**开发者路径**：01 → 02 → 03 → 04 → 05 → 08。此为 P0 实现顺序：01 提供基准概念与场景，02 的账户与 CSV 导入是 03 收支统计的数据来源，04、05 依赖前面模块的既有对象，08 作为横切文档在整体联调与合规检查时落地到设置页与首次告知流程。

**快速了解路径**：仅读本 README + 01。读完即可掌握产品定位、硬约束、全部关键决策与模块架构，判断是否需要深入其余文档。
