### 1.2 与共享概念及既有场景的关系

- **储蓄目标**（01 §5.6）：规划对象，由目标金额、截止日期（本文档界面用语为"目标日期"）与已储蓄金额构成；进度 = 已储蓄金额 ÷ 目标金额；状态为进行中 / 已达成 / 已放弃。储蓄目标是"达成下限"（要攒到），与预算的"约束上限"（不要花超）方向相反、互不推导，本文档不将两者做任何自动换算。
- **风险等级**（01 §5.7）：五级标签体系（低 / 中低 / 中 / 中高 / 高），可由用户自评得出，结果仅为建议值、用户可手动调整；其用途是决定配置教育展示的示例比例档位，不构成任何投资建议。
- **账户与资产类型**（01 §5.1）：配置示例的资产类别口径与账户资产类型的三分类（现金与活期、定期与理财产品、基金持仓）完全一致，不引入第四类。
- **场景 4**（01 §3）：目标卡片须展示目标名称、目标金额、已储蓄金额、进度百分比、剩余天数；已储蓄金额支持手动更新；须提供"按当前节奏的完成预期提示"。本文档第 2 章为该场景的完整行为定义。
- 本模块不依赖收支记录与预算周期的任何数据；风险测评结果仅被配置教育消费，不反过来影响储蓄目标的任何计算（01 §5.7：风险等级不是储蓄目标的输入或输出）。

## 2. 储蓄目标（F1）

### 2.1 目的

让用户为具体用途（换数码设备、旅行、应急备用金、毕业过渡金等中短期目标）设立攒钱计划，并随时看到三个可观察的答案：攒了多少（进度百分比）、还差多少（剩余金额）、来不来得及（剩余天数与完成预期提示）。储蓄目标不与任何账户绑定计算，是独立的规划对象。

### 2.2 布局

- **主列表**：每张目标卡片自上而下展示：目标名称与状态标记（进行中 / 已达成 / 已放弃，逾期时另加"已到期"角标）、目标金额、已储蓄金额、进度百分比与进度条、剩余天数、完成预期提示（一行）、"记一笔存入"按钮与更多操作菜单（编辑 / 删除 / 归档）。
- **排序规则**：逾期的进行中目标置顶并高亮，其余进行中目标按目标日期从近到远排列，已达成与已放弃的目标沉至列表底部。
- **目标详情**：点击卡片展开详情区，展示备注全文与存入记录列表（每条含日期、方向、金额、备注，可修改与删除），并提供"添加存入 / 取出"入口。
- **空态**：无任何目标时，页面展示引导文案（"为你的下一个目标开始攒钱"）与"新建目标"按钮。
- **归档列表**：页面底部折叠入口，点开显示全部已归档目标（仅查看、取消归档、删除）。

### 2.3 目标创建

**触发**：用户在储蓄目标页点击"新建目标"按钮，或空态引导中的"新建目标"按钮。

**字段定义**：

| 字段 | 格式 / 约束 | 必填 | 说明 |
|---|---|---|---|
| 目标名称 | 自由文本，1～20 字 [Assumption, TBD] | 是 | 输入框下方预置常用模板供点选：换数码设备、旅行、应急备用金、毕业过渡金；也可自由输入 |
| 目标金额 | 金额，大于 0，保留两位小数 | 是 | — |
| 目标日期 | 日期（即 01 §5.6 的"截止日期"） | 是 | 不得早于创建当天 |
| 初始已储蓄 | 金额，≥ 0，保留两位小数 | 否 | 用于目标创建前已经攒了一部分钱的场景；填写后生成首条存入记录（日期 = 创建当天，备注自动标记"初始金额"） |
| 备注 | 自由文本，≤ 200 字 [Assumption, TBD] | 否 | 如"二手平台看中的型号" |

系统自动生成并记录：创建日期、已储蓄金额（初始为 0 或初始已储蓄值）、进度、状态（进行中）、归档标记（否）。

**处理规则**：逐字段校验（见 2.7 异常场景），全部通过后保存；新目标卡片立即出现在主列表中，进度按初始已储蓄金额计算。

**结果与状态变化**：新增一条状态为"进行中"的储蓄目标；若初始已储蓄 ≥ 目标金额，创建即判定为已达成（见 2.5）。

### 2.4 已储蓄金额与进度计算

**已储蓄金额的来源口径（手动累计式）**：已储蓄金额 = 该目标全部存入记录的净额（存入总额 − 取出总额），不支持直接修改总值，只通过增删改单条记录变化。存入记录字段：

| 字段 | 格式 / 约束 | 必填 | 说明 |
|---|---|---|---|
| 日期 | 日期 | 是 | 默认填充为当天，可改 |
| 方向 | 存入 / 取出 | 是 | 取出用于表达"从攒的钱里挪用了部分"的场景 |
| 金额 | 大于 0，保留两位小数 | 是 | — |
| 备注 | 自由文本，≤ 50 字 [Assumption, TBD] | 否 | — |

**采用手动累计式的理由**：

1. 场景 4 要求提供"按每周存入 ¥X 的节奏可按期达成"的完成预期提示，该提示必须依据存入行为的时间分布计算；只有逐笔记录能还原节奏，一次性手填总值不能。
2. 储蓄目标是规划对象，与资产快照（事实测量）是两个概念（01 §5.6），已储蓄金额采用独立的手动口径，正是保持"计划数"与"实有数"允许不一致的设计。
3. 关联账户资产快照自动取值在 01 §5.6 中为 [关联取值方案 TBD]，本模块不实现，仅保留为后续扩展方向；扩展引入前，手动累计为唯一口径。

**进度百分比**：进度 = 已储蓄金额 ÷ 目标金额（01 §5.6 定义），展示时向下取整为整数百分比（如 99.6% 展示为 99%），仅当判定达成时展示 100%——保证"展示 100%"与"状态已达成"严格同时成立。已储蓄金额超过目标金额时，进度条封顶 100%，并在卡片上提示"已超出目标金额 ¥X"。

**剩余天数**：剩余天数 = 目标日期 − 今天（按自然日）。今天早于目标日期时展示"剩余 N 天"；等于时展示"今日截止"；已过时展示"已到期 N 天"（处理见 2.5）。

**完成预期提示**（场景 4 的细化）：

- 展示前提：存入记录 ≥ 2 条，且自首条存入记录日期至今天 ≥ 7 天，且每周平均存入 > 0，且目标未达成 [Assumption, TBD：前提参数与下方计算公式为推断性设定，上线前经试用数据校准]。
- 每周平均存入 =（存入总额 − 取出总额）÷ 经过周数；经过周数 = 自首条存入记录日期至今天的天数 ÷ 7，向上取整且至少为 1。
- 预计达成日期 = 今天 + ⌈(目标金额 − 已储蓄金额) ÷ 每周平均存入 × 7⌉ 天。
- 预计达成日期不晚于目标日期时，展示："按每周存入 ¥X 的节奏，预计可按期达成（约 M 月 D 日）"。
- 晚于目标日期时，展示："按每周存入 ¥X 的节奏，预计 M 月 D 日达成，比目标日期晚 N 天；若想按期达成，每周需存约 ¥Y"。其中 ¥Y = 剩余金额 ÷ 剩余周数，剩余周数 =（目标日期 − 今天）÷ 7，向上取整且至少为 1。
- 不满足展示前提（如记录不足、净取出导致每周平均 ≤ 0）时，展示"记录更多存入后，可查看达成预期"。

**结果与状态变化**：任何存入记录的新增、修改、删除，以及目标金额的修改，都触发已储蓄金额、进度百分比、完成预期提示的即时重算与展示刷新。

### 2.5 状态与完成判定

状态机沿 01 §5.6 的三态定义：**进行中 / 已达成 / 已放弃**。归档不是状态，是独立的管理标记（见 2.6）。

| 当前状态 | 事件 | 迁移 | 触发方式 |
|---|---|---|---|
| —（不存在） | 创建目标 | 进行中 | 用户创建 |
| 进行中 | 已储蓄金额 ≥ 目标金额 | 已达成 | 自动（存入记录保存或目标金额下调后重算时） |
| 进行中 | 用户确认放弃 | 已放弃 | 用户操作（放弃入口，需二次确认） |
| 已达成 | 目标金额上调至超过已储蓄金额 | 进行中 | 用户编辑后自动重算 |
| 已达成 / 已放弃 | 归档 / 取消归档 / 删除 | 状态不变 | 用户操作 |

- **达成判定与展示**：已储蓄金额首次达到或超过目标金额的时刻，状态自动转为已达成，记录达成日期（触发达成的存入记录日期）；卡片显示"已达成"标记与达成日期，进度展示 100%（超额时附超出金额提示）。
- **目标日期已到但未达成（逾期）**：到期次日起，状态**保持"进行中"**，不自动转为已放弃（用户可能仍在攒）；卡片置顶并高亮"已到期 N 天"角标，同时给出三个明确选项：
  1. **延期**：修改目标日期为未来日期，逾期标记消失，回到正常进行中展示；
  2. **放弃**：二次确认后转"已放弃"，记录放弃日期；
  3. **继续跟进**：不做操作，卡片持续显示已到期天数，直至达成或用户再操作。

### 2.6 编辑、删除与归档

**编辑**：

| 状态 | 可编辑性 | 规则 |
|---|---|---|
| 进行中（含逾期） | 全部字段可编辑 | 修改目标金额或日期后，进度、剩余天数、完成预期提示即时重算；逾期目标改期后回到正常展示 |
| 已达成 | 可编辑 | 上调目标金额使已储蓄 < 新目标时，状态回到"进行中"，卡片提示"目标金额已调整，目标重新开启" |
| 已放弃 | 通过"重新开启"入口 | 点击并确认后转"进行中"，随后可编辑字段；无直接编辑路径 |

**删除**：任意状态（含归档中）均可删除；二次确认弹窗明示删除范围为"该目标及其全部 N 条存入记录，删除后无法恢复"；确认后目标与存入记录一并移除，列表即时刷新。

**归档**：

| 规则 | 内容 |
|---|---|
| 可归档条件 | 仅"已达成"或"已放弃"的目标；进行中（含逾期）目标的归档按钮置灰，点击提示"仅已结束的目标可归档" |
| 归档效果 | 目标移入归档列表（页面底部折叠入口），数据与状态不变 |
| 归档中可执行 | 查看、取消归档（移回主列表）、删除；不支持编辑（需先取消归档） |
| 设计理由 | 主列表只保留用户当前关注的目标，历史目标归档避免干扰；不改变状态机，保证与 01 §5.6 三态一致 |

### 2.7 异常场景

| 场景 | 系统行为 |
|---|---|
| 目标金额为空、为 0、为负数或非数字 | 阻止保存，字段下方提示"目标金额必须大于 0" |
| 目标名称为空或超过 20 字 | 阻止保存，提示"请输入 1～20 字的目标名称" |
| 创建时目标日期为空或早于今天 | 阻止保存，提示"目标日期不能早于今天" |
| 编辑逾期目标但未修改日期（原值为过去日期） | 允许保存（否则逾期目标无法修改其他字段）；仅当用户把日期改为早于今天的新值时阻止 |
| 已储蓄金额超过目标金额 | 合法；进度展示 100%，卡片提示"已超出目标金额 ¥X"，状态转已达成 |
| 存入 / 取出记录金额 ≤ 0 或非数字 | 阻止保存，提示"金额必须大于 0" |
| 取出后累计已储蓄金额为负 | 阻止保存，提示"取出金额不能超过当前已储蓄金额"。理由：负的已储蓄金额无业务含义，该约束为简化决策 [Assumption] |
| 删除含存入记录的目标 | 二次确认明示删除范围与不可恢复；确认后执行 |
| 对进行中目标点击归档 | 按钮置灰并提示原因，不执行 |
| 目标日期到期未达成 | 见 2.5 逾期规则：置顶高亮 + 三选项，不自动改状态 |

## 3. 风险测评问卷（F2）

### 3.1 目的

用面向小白的措辞，从风险态度、亏损承受反应、投资经验、资金用途期限四个维度自评，得出用户的风险偏好等级，作为配置示例的默认展示档位。测评结果仅为建议值（01 §5.7），不作为任何操作指令。

### 3.2 布局与触发

- **布局**：问卷以逐题形式呈现（每屏一题，含进度指示"第 X / 7 题"），选择后自动进入下一题；最后一题后展示结果页（风险偏好类型、等级标签、对应 R 级解释、重新测评入口、"查看我的配置示例"入口）。
- **触发**：三个入口——首次初始化引导中的可选步骤"风险偏好自评"（01 场景 6，可跳过）；配置教育页未完成测评时的引导卡片；配置教育页已完成后结果卡片上的"重新测评"按钮（见 3.7）。

### 3.3 题目结构

共 4 个维度、7 题，每题 4 个选项。[Assumption, TBD] 题量定为 7 题（≤ 8 题上限）的理由：主画像用户对操作步骤复杂度敏感、遇到不理解倾向放弃（01 §2.1），逐题作答下 7 题约 2 分钟可完成；四个维度覆盖风险偏好自评的最小必要信息，压缩至 7 题是在信息量与完成率之间的推断性取舍，上线前可通过小样本试用校准题量与措辞。题目文案如下（属产品设计内容）：

**维度一：风险态度（2 题）**

| 题号 | 题目 | 选项（分值） |
|---|---|---|
| A1 | 假设你攒了一学期的钱做了某种安排，一个月后整体跌了 10%，你会？ | a. 立刻全部取出，换更稳的方式（1）；b. 先取出一部分，剩下的再看看（2）；c. 不动，等它涨回来（3）；d. 趁便宜再补一点（4） |
| A2 | 下面哪句话更接近你的想法？ | a. 亏一分钱都不行，稳最重要（1）；b. 可以接受一点点波动，但别太大（2）；c. 有涨有跌很正常，能接受（3）；d. 想追求更高回报，跌了也认（4） |

**维度二：亏损承受反应（1 题）**

| 题号 | 题目 | 选项（分值） |
|---|---|---|
| B1 | 为目标攒的这笔钱，短期内（半年内）最多能接受它暂时亏多少？ | a. 一点都不能亏（1）；b. 亏 5% 以内（2）；c. 亏 5%～20%（3）；d. 亏 20% 以上也能接受（4） |

**维度三：投资经验（2 题）**

| 题号 | 题目 | 选项（分值） |
|---|---|---|
| C1 | 你买过哪些类型的理财或基金？（按最高的一档选） | a. 没买过，只有现金和活期（1）；b. 余额宝、零钱通或银行定期（2）；c. 银行理财或理财产品（3）；d. 基金（含股票型基金）（4） |
| C2 | 你持有过最长时间的一笔理财或基金是？ | a. 没持有过（1）；b. 3 个月以内（2）；c. 3 个月到 1 年（3）；d. 1 年以上（4） |

**维度四：资金用途期限（2 题）**

| 题号 | 题目 | 选项（分值） |
|---|---|---|
| D1 | 这次想规划的这笔钱，大概什么时候会用到？ | a. 半年内（1）；b. 半年到 1 年（2）；c. 1 到 3 年（3）；d. 3 年以上（4） |

## 4. 风险分级配置示例（F3）

### 4.1 目的

在用户完成风险测评后，展示对应风险等级的三类资产配置比例示意，让零基础用户直观建立"不同风险偏好对应不同的钱怎么放"的认知。全部内容为教育性科普示意，不构成投资建议、不指向任何具体产品。

### 4.2 布局与触发

- **布局**（配置教育页的配置示例区，自上而下）：等级标签行（五档可点击切换，当前档高亮，用户测评档位带"我的"角标）；当前档的水平比例条（三段着色分段，每段显示百分比）；三类资产的图例与一句浅白解释；"仅为教学示意"标注与完整合规声明（见第 5 章）；"查看五档对比"切换入口。
- **触发**：进入配置教育页（默认展示用户测评档位，未测评时见 3.6）；点击任一等级标签；完成测评提交后自动定位；开启"五档对比"视图。

### 4.3 展示逻辑与处理规则

- 按当前选中的风险等级，展示该档三类资产的比例示意（比例条 + 图例 + 百分比数字）。
- "五档对比"视图：五条比例条纵向并列，直观呈现档位间的结构差异，便于横向认知。
- 配置示例区域不因储蓄目标、资产快照的任何数据变化而变化；它只消费风险等级这一个输入。
- 结果与状态变化：切换等级仅改变展示内容，不产生任何用户数据的写入。

### 4.4 资产类别口径与概念解释

资产类别仅三类，口径与 01 §5.1 账户资产类型完全一致，不引入第四类：

| 资产类别 | 一句浅白解释（沿用 01 已定义概念） |
|---|---|
| 现金与活期 | 随时能用的钱：钱包现金、银行卡活期，以及余额宝、零钱通这类零钱理财（底层是货币基金——主要投资短期存款、债券等低风险品种的基金，收益较低但波动小、可快速取出） |
| 定期 / 理财产品 | 要放满约定期限才方便取出的钱：银行定期存款、银行理财、理财通理财等；通常收益高于活期，展示的收益率是参考值而非承诺，提前取出受限制 |
| 基金持仓 | 通过支付宝、微信、银行等渠道申购赎回的场外基金；按净值（每份基金单位的价格）计价，金额随市场涨跌波动，可能亏损 |

## 5. 合规声明（F4）

### 5.1 目的

落实 01 号文档约束 4（内容涉及投资）：全部投资相关内容统一标注"教育性信息，不构成投资建议"，并在首次进入相关页面时显著展示，使配置教育内容始终处于明确的合规边界内。

### 5.2 展示位置

- 配置教育页的配置示例区域**固定展示**合规声明：不随等级切换消失，不折叠隐藏，始终与比例示意同屏可见。
- 精简版（一行）常驻展示，"查看完整声明"可展开全文（即 5.3 建议稿）。
- 储蓄目标页不涉及投资内容，不展示投资类声明（储蓄目标是攒钱计划，不是投资安排）。

### 5.3 完整文案（建议稿）

> **教育性信息声明**
> 1. 本页面全部内容（含风险测评结果与资产配置比例示例）仅为教育性信息，不构成投资建议，亦不构成对任何金融产品的推荐或邀约。
> 2. 配置示例中的资产类别比例仅为科普示意，不代表任何具体产品的实际构成；示例比例未与任何持牌机构核对，不应作为实际配置依据。
> 3. 市场有风险，投资需谨慎。任何理财与基金产品均可能产生亏损，过往表现不代表未来收益。
> 4. 请在充分理解相关产品与自身情况后独立决策，必要时向持牌机构的专业人士咨询。
> 5. 本应用不提供投资咨询、投资顾问或资产管理业务。

### 5.4 首次进入配置教育页的提示行为

- 用户**首次**进入配置教育页时，在页面内容上方展示显著提示层：声明要点（浅白一句话版："本页内容只是科普示意，不构成投资建议；市场有风险，投资需谨慎"）+ "我已知晓，继续查看"按钮 + "查看完整声明"链接。
- 提示层为**非阻断式**（不遮罩页面、不阻止浏览），用户未点击确认时持续显示；理由：阻断式提示与"引导可跳过"的产品精神不符（01 场景 6），且声明本身需要的是持续在场而非强制拦截。
- 点击"我已知晓"后，提示层收起为此后每次进入均显示的常驻精简声明条（5.2）。

### 5.5 状态与异常场景

| 项目 | 内容 |
|---|---|
| 声明确认状态 | 未确认（首次进入后）/ 已确认（点击"我已知晓"后），仅记录一次，不再重复弹出 |
| 状态变化 | 未确认 → 已确认（点击按钮，不可逆）；此后每次进入仅显示常驻精简声明条 |
| 异常：用户始终不点确认 | 提示层持续显示在页面顶部，不阻断浏览，功能可正常使用 |
| 异常：未确认期间查看完整声明 | 链接可正常展开全文，展开不等于确认，提示层保持 |
