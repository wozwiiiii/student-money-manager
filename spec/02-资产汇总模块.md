## 1. 模块定位与边界

### 1.1 模块定位

微信理财通、支付宝、各大银行均不向个人第三方应用开放资产查询接口（01 第 4 章约束 1），因此「我一共有多少钱」没有任何单一入口可查。本模块以「用户手动登记账户 + 主动更新资产快照」的方式回答 01 号文档的问题 P1（资产总貌不可见），对应 01 场景 5（查看资产总览）与场景 6（首次初始化设置）。产品围绕低频快照更新而非实时同步设计：所有数字来自用户录入，页面始终标注最近更新时间、不出现「实时余额」类字样。

### 1.2 功能构成

| 功能 | 内容 | 对应 01 号文档 |
|---|---|---|
| 账户管理 | 三类资产类型账户的登记、修改、删除与命名自定义 | 5.1 节、场景 6 |
| 资产快照录入 | 逐账户录入时点余额，形成快照与历史列表 | 5.2 节、场景 5、场景 6 |
| 账单 CSV 导入 | 支付宝/微信导出账单文件转为收支记录（权威定义处） | 5.3 节、5.4 节、场景 3 |
| 资产总览 | 总资产汇总、账户结构、资产趋势图 | 场景 5、第 1.4 节预期结果 1 |

### 1.3 模块边界（不做什么）

- 不提供任何形式的自动同步、余额变动自动提醒（01 约束 1）。
- 资产类型仅限三类：现金与活期、定期与理财产品、基金持仓；明确不含黄金等贵金属及另类资产（01 第 6.1 节）。
- 不内置、不核实任何理财产品的收益率数值；用户填写的收益率仅作展示参考（01 约束 4）。
- 股票分析、银行产品信息库为 P1 二期内容，不在本模块。

### 1.4 与其他模块的关系

- **账单 CSV 导入同时服务两个模块**（01 第 6.2 节）：导入的直接产物是收支记录，服务 03 号文档（收支与预算）的统计与预算功能；其全部规则以本文档第 4 章为准。银行流水文件导入不在本文档范围（由 03 号文档定义）。
- **储蓄目标可关联资产快照取值**（01 第 5.6 节）[关联取值方案 TBD]。
- **资产趋势与收支统计独立计算、互不推导**（01 第 5.2、5.3 节）：CSV 导入只产生收支记录，不改变本模块任何资产数字。

## 2. 功能一：账户管理

### 2.1 目的

把现实中分散在微信、支付宝、银行等处的资金存放渠道逐一登记为本产品的账户（见 01 第 5.1 节）。账户是「钱放在哪里」的记账容器，是本模块其余三个功能的基础：没有账户就没有快照的录入对象，也没有总览的汇总对象。

### 2.2 布局

| 区域 | 内容 |
|---|---|
| 账户列表 | 按「现金与活期 / 定期与理财产品 / 基金持仓」三类分组；每组组头显示类型名称、浅白说明（默认一句、点击展开 [展开样式 TBD]）与组内小计；组内为账户卡片（名称、当前余额或「—」、最近快照时间） |
| 新建入口 | 页面右上与每组组头各有一个「添加账户」按钮，点击后先选资产类型 |
| 账户卡片操作 | 点击卡片进入账户详情（完整字段、该账户历次快照值）；卡片上有「编辑」「删除」入口 |

首次初始化引导（01 场景 6）中「创建账户」步骤使用与新建账户相同的表单，每一步可跳过。

### 2.3 触发

| 触发 | 说明 |
|---|---|
| 首次进入应用的分步引导 | 见 01 场景 6 |
| 在账户管理页或资产总览页主动新建 | 任意时刻 |
| 在账户详情或卡片上发起编辑、删除 | 任意时刻 |

### 2.4 处理规则

#### 2.4.1 新建通用流程

选择资产类型（三选一，每项附一句浅白说明）→ 填写该类型对应的表单 → 保存。资产类型一经保存不可修改；如登记错误，需删除账户后重建，余额数据不会自动迁移（见 2.4.7）。

#### 2.4.2 现金与活期类账户的登记

适用对象：口袋现金、银行卡活期存款、余额宝 / 零钱通（两者底层均为货币基金，即主要投资于短期存款、债券等低风险品种的基金，收益较低但波动小、可快速取出使用，见 01 第 1.1 节概念说明）。

- 登记时填写：账户名称、是否计入总资产、（可选）备注。
- 余额不在登记时填写，而在资产快照中更新（见第 3 章）；创建完成后界面引导「去录入第一次快照」。

#### 2.4.3 定期与理财产品类账户的登记

适用对象：理财通理财、银行定期存款、银行理财（定期理财指资金需存放满约定期限后才能取出的产品，见 01 第 1.1 节概念说明）。

- 登记时填写：账户名称、本金、存入/购买日期、期限；到期日按「存入日期 + 期限」自动计算填入，可手动修改。
- 展示收益率：用户可从产品页面抄录收益率填入。该字段旁固定展示说明：「展示收益率为参考值而非承诺，实际收益以产品到期结算为准。」本产品不内置、不核实任何产品的收益率数值 [若后续内置参考值，数值 TBD]。
- 风险等级：选填，按 01 第 5.7 节的五级标签（低 / 中低 / 中 / 中高 / 高）选择，并提供「不确定」选项。
- 当前价值不在此处填写，而在每次资产快照中更新：用户从产品页面抄录展示的「当前价值 / 持有金额」[估值口径 TBD，见 01 第 5.2 节]。

#### 2.4.4 基金持仓类账户的登记

适用对象：场外基金（指通过支付宝、微信、银行等渠道申购和赎回、而非在证券交易所内买卖的基金，见 01 第 2.1 节）。

- 登记时填写：账户名称、（可选）基金名称、是否计入总资产。
- 份额与净值不在登记时填写，而在每次资产快照更新时录入（见 3.4.1）。
- 界面在相关字段处展示概念解释：份额 = 持有的基金份数（买入金额 ÷ 买入时的净值）；净值 = 每份基金的单位价格，持有金额 = 份额 × 净值，随净值涨跌变化（与 01 第 5.2 节定义一致）。

#### 2.4.5 账户命名自定义

- 创建时提供常用默认名（余额宝、零钱通、银行卡、现金、银行定期、银行理财、理财通理财、场外基金等 [默认名清单 TBD]），均可自由修改。
- 允许同名账户（现实中可能持有多张同渠道的卡）；保存同名账户时提示一次「已存在同名账户」，不阻止保存，列表以创建时间辅助区分。
- 名称长度上限 [TBD]。

#### 2.4.6 账户修改规则

| 字段 | 可否修改 | 说明 |
|---|---|---|
| 账户名称、备注、基金名称 | 可 | 随时修改，不影响已有快照与收支记录 |
| 本金、存入/购买日期、期限、到期日、展示收益率、风险等级 | 可 | 修改仅改变账户详情展示，不改动任何已保存的快照数值 |
| 资产类型 | 不可 | 见 2.4.1 |
| 是否计入总资产 | 可 | 切换后当前总资产立即按新设置计算；历史快照中已固定的总资产数值不回溯重算（见 5.4.1、5.4.3） |

#### 2.4.7 账户删除规则

按账户名下是否有数据分两种情形：

1. **账户无任何快照记录、且无关联收支记录**：弹出确认一次 → 删除。
2. **账户有快照记录或关联收支记录**：弹出确认框，逐条列明影响，用户需勾选「我已了解上述影响」后方可删除：
   - 已有历史快照保持不变：历史快照中该账户的余额与当时的总资产数值不改动，资产趋势图历史记录点不变化（理由见 5.4.3）；
   - 未来的新快照不再包含该账户；
   - 所属账户指向该账户的收支记录全部保留不删除，其「所属账户」显示为原账户名并附「已删除」标记 [展示样式 TBD]。
   - 删除后不可恢复 [是否提供短期撤销窗口 TBD]。

「不计入总资产」的账户与普通账户的删除规则相同。

### 2.5 结果与状态变化

- 新建：账户立即出现在对应类型分组，当前余额显示「—」并标「待录入快照」，不计入总资产（见 5.4.1）。
- 修改：界面即时刷新；涉及展示的字段（到期日、收益率等）同步更新。
- 删除：账户从列表移除；历史快照不受影响；当前总资产按剩余账户重新计算（被删账户原贡献的余额不再计入）。

### 2.6 字段定义

#### 2.6.1 现金与活期类账户

| 字段 | 必填 | 说明 |
|---|---|---|
| 账户名称 | 是 | 自由文本，创建时提供常用默认名 [清单 TBD] |
| 资产类型 | 是 | 固定为「现金与活期」，创建后不可修改 |
| 是否计入总资产 | 是 | 默认「计入」 |
| 当前余额 | — | 不作为账户固有属性存储，始终显示该账户最近一次资产快照的余额；无快照时显示「—」（见 01 第 5.1 节） |
| 备注 | 否 | 自由文本 |
| 创建时间 | 自动记录 | 用于列表排序与同名账户区分 |

#### 2.6.2 定期与理财产品类账户

| 字段 | 必填 | 说明 |
|---|---|---|
| 账户名称 | 是 | 自由文本，默认名如「银行定期」「理财通理财」 |
| 资产类型 | 是 | 固定为「定期与理财产品」，创建后不可修改 |
| 本金 | 是 | 最初存入/投入的金额；非负数字、最多两位小数 |
| 存入/购买日期 | 是 | 不晚于当天 |
| 期限 | 是 | 预置选项 + 自定义天数 [选项集 TBD] |
| 到期日 | 自动计算 | 存入日期 + 期限；可手动修改，不得早于存入日期 |
| 展示收益率 | 否 | 用户抄录产品页面展示的收益率，仅作参考展示；界面固定附「参考值而非承诺」说明（见 2.4.3）；本产品不内置该数值 [TBD] |
| 风险等级 | 否 | 五级标签（见 01 第 5.7 节）或「不确定」 |
| 是否计入总资产 | 是 | 默认「计入」 |
| 当前价值 | — | 取最近一次资产快照（见 2.4.3、3.4.1） |
| 备注 | 否 | 自由文本 |

#### 2.6.3 基金持仓类账户

| 字段 | 必填 | 说明 |
|---|---|---|
| 账户名称 | 是 | 自由文本，默认名如「场外基金」 |
| 资产类型 | 是 | 固定为「基金持仓」，创建后不可修改 |
| 基金名称 | 否 | 自由文本（如「某某指数基金」） |
| 是否计入总资产 | 是 | 默认「计入」 |
| 当前份额 | — | 取最近一次资产快照；份额 = 持有基金的份数 |
| 当前净值 | — | 取最近一次资产快照；净值 = 每份基金的单位价格 |
| 当前金额 | — | 份额 × 净值，或用户直接抄录基金页面的「持有金额」 |
| 备注 | 否 | 自由文本 |

### 2.7 状态

| 状态 | 含义 | 界面可见性 |
|---|---|---|
| 使用中 | 正常参与快照录入与总览展示；其下含「计入 / 不计入总资产」两种属性取值 | 账户列表可见；不计入的账户在总览单独列出（见 5.4.1） |
| 已删除 | 账户已移除，不再出现在任何管理界面 | 不可见；仅收支记录的「所属账户」处保留原名称并附「已删除」标记 |

### 2.8 异常场景

| 场景 | 产品行为 |
|---|---|
| 未填账户名称即保存 | 保存不可用，名称输入框提示「请填写账户名称」 |
| 本金等金额输入非数字或负数 | 行内提示，保存不可用 |
| 到期日被改到早于存入/购买日期 | 提示「到期日不能早于存入日期」，保存不可用 |
| 保存同名账户 | 提示一次「已存在同名账户」，不阻止保存 |
| 删除有数据的账户 | 走 2.4.7 情形 2 的确认流程 |
| 删除全部账户 | 资产总览回到空态引导（见 5.8） |

## 3. 功能二：资产快照录入

### 3.1 目的

资产快照（见 01 第 5.2 节）是「某时刻一共有多少」的时点测量，是资产趋势图的唯一数据来源。因各平台不开放查询接口，快照只能手动录入；本功能以「默认带出上次值 + 异常变化提醒」的防呆设计，把每次更新的录入成本压到最低，支撑低频（以周为典型）更新节奏。

### 3.2 布局

| 区域 | 内容 |
|---|---|
| 入口 | 资产总览页「更新快照」按钮 |
| 录入页 | 页头为快照时间（默认当前时刻）；主体为按三类资产类型分组的账户清单，每账户一个输入项；页脚「保存快照」按钮 |
| 快照历史列表 | 资产总览页「快照历史」入口进入，按快照时间倒序排列 |

### 3.3 触发

| 触发 | 说明 |
|---|---|
| 用户点击「更新快照」 | 见 01 场景 5 |
| 首次初始化引导中完成账户创建后 | 引导内直接进入首次快照录入，保存后生成第一条快照（见 01 场景 6） |

### 3.4 处理规则

#### 3.4.1 录入流程

1. 点击「更新快照」，系统列出全部「使用中」账户（含「不计入总资产」的账户，其数值同样录入并保留在快照中，便于日后改回计入时数据连续 [Assumption, TBD]）。
2. 每个账户的输入项默认带出上一次快照的值；从未录入过的显示为空。
3. 快照时间默认当前时刻，可改为过去的时间用于补录，不可晚于当前时刻。
4. 点击「保存快照」，生成一条快照记录：快照时间 + 各账户余额 + 总资产。

各资产类型的输入项：

| 资产类型 | 输入项 | 说明 |
|---|---|---|
| 现金与活期 | 余额 | 元，最多两位小数 |
| 定期与理财产品 | 当前价值 | 从产品页面抄录「当前价值 / 持有金额」[估值口径 TBD]；默认带出上次值或本金 |
| 基金持仓 | 方式 A：份额 + 净值；方式 B：持有金额 | 方式 A 由系统计算金额 = 份额 × 净值；方式 B 直接抄录基金页面的「持有金额」；两种方式等价，任选其一 |

#### 3.4.2 必填字段

| 字段 | 必填性 |
|---|---|
| 快照时间 | 必填（默认已填） |
| 各使用中账户的余额 / 当前价值 / 持有金额 | 首次快照时逐账户必填；此后默认预填上次值，余额未变化的账户无需修改，页面提示「与上次相同可保持不变」 |

因保存要求每个使用中账户均有数值，快照保存后不存在账户值缺失的情况。

#### 3.4.3 校验规则

| 校验项 | 规则 | 反馈 |
|---|---|---|
| 金额格式 | 非负数字，最多两位小数，整数位数上限 [TBD] | 行内提示，保存不可用 |
| 快照时间 | 不得晚于当前时刻 | 提示「快照时间不能晚于现在」 |
| 补录时间早于现有最早快照 | 允许，但需确认 | 弹出「该时间早于你最早的快照（显示日期），确认补录？」（防止年份输错） |
| 余额大幅变化 | 与上次快照相比偏差超过 ±50% [阈值 TBD] | 该账户行提示「与上次相差较大，请核对」，需确认后方可保存 |
| 净值 | 正数；常见区间参考 [典型区间 TBD] | 超出参考区间时行内提示核对 |
| 同分钟重复快照 | 快照时间精确到分钟，同一分钟只允许一条 | 提示「该时间已有快照，请调整时间或编辑原快照」 |

#### 3.4.4 快照历史列表

| 要素 | 内容 |
|---|---|
| 每条记录 | 快照时间、总资产金额、（展开后）各账户余额明细、数据来源、最后编辑时间 |
| 排序 | 按快照时间倒序 |
| 操作 | 展开明细、编辑、删除 |

#### 3.4.5 快照编辑规则

- 可编辑项：快照时间、各账户余额。
- 保存后：该快照的总资产重新计算；资产趋势图的对应记录点随之移动或变化。
- 编辑留痕：历史列表中显示「最后编辑于 X 时间」，与未编辑过的快照区分。

#### 3.4.6 快照删除规则

- 删除需确认，确认框说明影响：资产趋势图减少对应记录点；若删除的是某账户最近一次快照，该账户「当前余额」回退至更早一次快照的值；若删除的是该账户唯一一次快照，该账户余额显示「—」并标「待录入快照」、不计入总资产（见 5.4.1）。
- 删除不可恢复 [撤销窗口 TBD]。

### 3.5 结果与状态变化

保存快照后：生成一条快照记录；资产总览页的总资产、各账户当前余额、「最近快照时间」标记即时刷新；快照总数达到 2 条及以上时，资产趋势图出现或更新（见 5.4.3）。编辑与删除快照后，上述展示与趋势图同步刷新。

### 3.6 字段定义

| 字段 | 说明 |
|---|---|
| 快照时间 | 精确到分钟 |
| 账户余额明细 | 每个使用中账户一条：账户名称 + 余额 / 当前价值 / 持有金额；基金持仓按方式 A 录入时同时保留份额与净值 |
| 总资产 | 「计入总资产」账户的余额合计，保存时计算并固定 |
| 数据来源 | 手动录入（见 01 第 5.2 节） |
| 创建时间 / 最后编辑时间 | 留痕展示用 |

### 3.7 状态

快照记录无状态流转；仅以「最后编辑时间」区分是否被修改过。

### 3.8 异常场景

| 场景 | 产品行为 |
|---|---|
| 无任何使用中账户时点击「更新快照」 | 提示「请先创建账户」，并提供跳转账户管理的入口 |
| 首次快照存在空值账户 | 空值行标「待填写」，保存不可用 |
| 全部账户余额为 0 | 允许保存（可能真实为空） |
| 校验不通过 | 按 3.4.3 逐项提示，保存不可用 |

## 4. 功能三：账单 CSV 导入（套件内权威定义处）

> 本章定义支付宝 / 微信账单 CSV 导入的完整规则，03 号文档（收支与预算）直接引用本章。银行流水文件导入不在本章范围。

### 4.1 目的

把支付宝 / 微信导出的账单文件一次性转为本产品的收支记录（见 01 第 5.3 节），免去逐笔手动录入；配合分类自动映射与去重规则，使月末对账复盘（01 场景 3）收敛为「导出 → 导入 → 确认」三步。

### 4.2 布局

| 区域 | 内容 |
|---|---|
| 导入入口 | 收支记录页与资产总览页的「导入账单」按钮 [入口位置 TBD] |
| 导入向导（分步） | ① 选择文件并确认来源平台 → ② 预览 → ③ 结果 |
| 预览页 | 顶部统计条（总行数、将导入笔数、疑似重复笔数、未分类笔数）；明细列表（日期、描述、金额、方向、匹配分类、重复标记）；未分类项批量指定区；底部「确认导入」按钮（显示将导入笔数） |
| 帮助 | 「如何导出账单」指引（内容见 4.4.1），导入向导内可直接打开 |

### 4.3 触发

用户点击「导入账单」，选择一个由支付宝或微信导出的账单 CSV 文件。

### 4.4 处理规则

#### 4.4.1 平台导出入口指引（产品内帮助）

帮助内容随平台界面更新维护，路径如有变化以帮助最新版本为准：

| 平台 | 指引要点 |
|---|---|
| 支付宝 | 在支付宝 App 内进入「账单」页面，查找「开具交易流水证明 / 导出账单」类功能 [具体菜单路径 TBD]；选择时间范围后提交申请；文件通常经邮箱或应用内通知送达 [送达方式与时效 TBD] |
| 微信 | 进入「我 — 服务 — 钱包 — 账单」，查找「下载账单 / 导出」类功能 [具体菜单路径 TBD]；选择用于个人对账的下载类型 [选项名称 TBD] |
| 通用提示 | 导出时可能需要身份验证，文件送达可能有延迟；收到文件后请勿用 Excel 等表格软件打开并另存（可能改变文件内容导致乱码或格式变化），直接在本应用中导入 |

#### 4.4.2 文件格式说明

- 支持的文件：支付宝 / 微信官方导出的账单 CSV 文件（CSV：以逗号分隔各列的表格文本文件），且未经其他软件修改。
- 两家平台导出文件的列名与排列以实际文件为准 [具体列名清单 TBD]；产品按来源平台内置对应的字段读取模板，读取结果在预览页展示供用户核对。
- [Assumption, TBD] 平台导出文件的开头可能包含标题或说明文字行；导入时自动忽略无法识别为账单数据的行。
- 单个文件的大小上限 [TBD]；超限时提示按月分批导出、分批导入。

#### 4.4.3 字段映射规则

| 账单信息项 | 产品字段（收支记录） | 处理说明 |
|---|---|---|
| 交易时间 | 日期 | 转换为统一日期格式 |
| 金额 | 金额 | 保留两位小数 |
| 收/支方向 | 方向 | 按 4.4.4 转换为 收入 / 支出 / 转账 |
| 交易描述（商品名称、交易类型、交易对方、备注等） | 备注 | 拼接为一条描述文本 [拼接顺序 TBD]，同时作为分类匹配的依据 |
| 交易状态 | 过滤依据 | 仅导入交易成功 / 已完成的行 [非成功状态的处理细则 TBD] |
| 来源平台（导入时确认） | 数据来源 | 标记为「支付宝账单 CSV 导入」或「微信账单 CSV 导入」，对应 01 第 5.3 节的数据来源取值 |
| 所属账户 | 默认不映射 | 导入记录不指定所属账户（账单可能对应多个资金渠道，无法可靠判断），用户可事后逐笔补选；[Assumption, TBD] 是否依据账单中的支付方式信息自动匹配已建账户 |

#### 4.4.4 方向处理规则

| 账单中的方向标注 | 产品方向 | 是否计入收支统计 |
|---|---|---|
| 收入 | 收入 | 是 |
| 支出 | 支出 | 是 |
| 不计收支（如零钱通/余额宝转入转出、账户间转账、信用卡还款、理财买入等） | 转账 | 否 |
| 退款类记录 | [TBD：冲抵原支出，或按账单标注方向处理] | [TBD] |

两家平台方向列的具体取值文字以实际导出文件为准 [取值清单 TBD]，由字段读取模板统一转换。将「理财买入、零钱通转入」等记为转账而非支出，与 01 第 5.3 节「转账不产生收支、只改变资金位置」的记账规则一致：这些操作只是钱从一个口袋换到另一个口袋，总资产不变，因此不进入收支统计。

#### 4.4.5 分类自动映射规则

- 匹配方式：对交易描述文本做关键词包含匹配，命中即归类（分类与映射规则见 01 第 5.4 节，规则可自定义）。
- 内置默认规则示例（完整默认规则表 [TBD]）：

| 交易描述包含关键词（示例） | 匹配方向 | 匹配分类 |
|---|---|---|
| 食堂、外卖、奶茶、餐厅 | 支出 | 餐饮 |
| 地铁、公交、单车、打车 | 支出 | 交通 |
| 淘宝、京东、拼多多、快递 | 支出 | 购物 |
| 书店、文具、打印、网课 | 支出 | 学习 |
| 电影、游戏、视频会员 | 支出 | 娱乐 |
| 话费、流量 | 支出 | 通讯（预置分类，见 03 号文档 3.1 节内置支出分类清单） |
| 红包、转账（收入方向） | 收入 | 红包 |
| 兼职、劳务、工资 | 收入 | 兼职 |
| 生活费 | 收入 | 生活费 |

- 规则作用顺序：用户自定义规则优先于内置默认规则；多条规则命中同一笔时按规则列表顺序取第一条 [优先级细则 TBD]。
- 未匹配项的处理：预览页标记「未分类」，可单笔指定或批量指定分类；确认导入时仍为「未分类」的记录统一归入「其他」分类（支出与收入方向各一个）[「其他」分类的预置细节由 03 号文档统一确认]，与 01 第 5.3 节「分类必填」一致；未匹配笔数在预览页顶部单独提示。

#### 4.4.6 去重规则

- 判定条件：待导入条目与任意一条已有收支记录满足「同一日期 + 金额相同 + 交易描述相同」，即标记为疑似重复 [描述比对的模糊程度细则 TBD]。
- 比对范围：已保存的全部收支记录，不区分数据来源（手动录入的记录同样参与比对——用户可能先手动记过一笔，随后又在导入的账单中遇到同一笔）。
- 文件内部条目之间互不判重：同一天两笔金额与描述都相同的真实交易（如两次购买同一价格的饮料）都保留 [Assumption, TBD]。
- 用户选择处理：疑似重复项在预览页默认为「跳过」，用户可逐笔或批量改为「仍然导入」；页面单独显示疑似重复笔数。
- 重复导入同一文件的场景：第二次导入时，全部条目均与首次导入生成的记录命中判定条件；预览页顶部提示「本次 N 笔与已有记录疑似重复，你可能已导入过这份文件」，默认全部跳过；确认后结果为「0 笔导入、N 笔跳过」。

#### 4.4.7 失败与冲突处理

| 异常 | 界面表现 | 处理与反馈 |
|---|---|---|
| 文件格式不正确（非平台导出的 CSV，或被其他软件转存后结构改变） | 无法读出账单数据 | 提示「无法识别该文件，请使用支付宝/微信导出的原始 CSV 文件」，并提供打开帮助的入口 |
| 内容乱码（常见于文件被 Excel 等软件打开后另存，文字编码被改变） | 预览中文字无法辨认 | 提示「文件内容显示异常，请重新导出原文件，不要经其他软件转存」 |
| 空文件（无任何账单数据行） | 无可预览内容 | 提示「文件中没有账单数据，请确认导出时选择的时间范围」 |
| 部分行解析失败（某行缺少关键信息或格式异常） | 其余行正常进入预览 | 预览页列出「N 行无法读取」及原因摘要 [摘要粒度 TBD]；不影响其余行导入 |
| 交易状态为非成功（如已关闭的订单） | 不进入预览 | 按 4.4.3 过滤，过滤笔数在预览页说明 [是否展示 TBD] |

#### 4.4.8 导入流程与确认

1. 选择文件 → 2. 确认来源平台（系统按文件特征预选 [识别方案 TBD]，用户可手动改正）→ 3. 读取并进入预览 → 4. 处理未分类项与疑似重复项 → 5. 点击「确认导入」→ 6. 结果页。
任一步均可取消；取消不产生任何数据变化。

### 4.5 结果与状态变化

确认导入后：

- 生成收支记录，数据来源标记为对应平台（01 第 5.3 节），记录按日期进入收支记录列表。
- 覆盖时间段的收支统计、收支分类占比图与预算进度随之刷新（属 03 号文档模块，本章仅声明数据联动；本章不改变本模块任何资产数字，两套统计独立，见 01 第 5.2、5.3 节）。
- 结果页展示：导入成功笔数、跳过笔数（疑似重复）、无法读取行数、该文件覆盖时间段的收入合计与支出合计（对应 01 场景 3 的完成标志），并提供查看收支统计的入口。

### 4.6 字段定义

字段映射见 4.4.3；导入生成的收支记录字段全集以 01 第 5.3 节为准（日期、方向、金额、分类、所属账户、数据来源、备注）。

### 4.7 状态

导入流程状态：选择文件 → 读取中 → 预览 → 已确认导入 → 完成（或失败 / 已取消）。仅在「已确认导入」之后产生数据；取消与失败均不留存任何记录。

### 4.8 异常场景

| 场景 | 产品行为 | 定义处 |
|---|---|---|
| 导入文件格式错误 | 提示无法识别，引导重新导出原文件 | 4.4.7 |
| 空文件 | 提示无账单数据，请确认导出时间范围 | 4.4.7 |
| 重复导入同一文件 | 全部条目默认跳过，结果 0 笔导入、N 笔跳过 | 4.4.6 |
| 部分行解析失败 | 列出无法读取行数与原因，其余行正常导入 | 4.4.7 |
| 内容乱码 | 提示重新导出、勿经其他软件转存 | 4.4.7 |

## 5. 功能四：资产总览

### 5.1 目的

在一个页面回答「我现在一共有多少钱、分别放在哪里、最近变化如何」（01 场景 5）。页面所有数字来自用户录入的资产快照，始终标注最近快照时间，不出现「实时余额」类字样。

### 5.2 布局

| 区域 | 内容 |
|---|---|
| 总资产卡片 | 总资产金额 + 「最近快照：X 月 X 日 X 时 X 分」+ 「更新快照」按钮 |
| 账户结构 | 按「现金与活期 / 定期与理财产品 / 基金持仓」三组展示：每组小计与占总资产比例；组内账户卡片显示名称、当前余额、最近快照时间（定期组另显到期日与展示收益率；基金组另显份额、净值、金额） |
| 资产趋势图 | 折线图：横轴为快照时间、纵轴为总资产；提供时间范围切换 |
| 不计入的账户 | 单独区域列出（名称、余额），注明「未计入总资产」 |
| 空态引导 | 无账户 / 无快照时的占位提示（见 5.8） |
| 管理入口 | 「管理账户」「快照历史」「导入账单」入口 |

### 5.3 触发

打开资产总览页（是否为应用默认首页 [TBD]）。

### 5.4 处理规则

#### 5.4.1 总资产汇总口径

- 当前总资产 = 全部「使用中且计入总资产」账户的当前余额之和。
- 账户当前余额 = 该账户最近一次资产快照中的余额（见 01 第 5.1 节）。
- 某账户无任何快照：余额显示「—」并标「待录入快照」，**不计入总资产合计**（不按 0 计，避免误导性拉低总额）。
- 「不计入总资产」的账户：余额照常展示，但不参与合计。
- 切换账户的计入设置后：当前总资产立即按新设置计算；历史快照中已固定的总资产数值不回溯重算。
- 页面固定展示「最近快照时间」；数据新鲜度取决于用户的更新频率，长期未更新时展示的即历史快照（01 约束 1 的代价说明）。

#### 5.4.2 账户结构展示

- 分组固定为三类：现金与活期、定期与理财产品、基金持仓；组内排序规则 [TBD：按最近快照时间或名称]。
- 每组显示：小计（组内计入账户的余额之和）、占总资产比例（总资产为 0 时不显示比例）。
- 定期与理财产品组：账户卡片额外显示到期日、剩余天数（到期日已过的显示「已到期，请确认资金去向」）、展示收益率（附「参考值而非承诺」角标，见 2.4.3）。
- 基金持仓组：账户卡片额外显示份额、净值与金额（均取最近一次快照）。
- [TBD] 到期日在 30 天内的定期账户是否加「即将到期」标注 [阈值与样式 TBD]。

#### 5.4.3 资产趋势图数据口径

- 数据点：每一次资产快照对应图上一个记录点（横轴 = 快照时间，纵轴 = 该次快照的总资产）。
- 纵轴取值：直接使用快照保存时固定的总资产数值，不按当前账户设置重算历史。理由：历史快照是「当时的测量结果」，若在删除账户或切换计入设置后重算历史，会出现曲线整体位移的失真；历史记录点一经保存，仅随该快照的编辑或删除而变化（见 3.4.5、3.4.6）。
- 统计范围：全部快照，含补录的过去时间的快照（按快照时间排序插入）。
- 时间范围切换：全部 / 近 1 个月 / 近 3 个月 [选项集 TBD]，默认全部。
- 空数据处理：
  - 0 个快照：趋势图区域显示「完成首次快照后，这里将记录你的资产变化」及「去录入快照」入口；
  - 仅 1 个快照：显示「已有 1 次快照，再更新一次即可看到资产趋势」（对应 01 第 1.4 节预期结果 1：完成 2 次快照更新后展示趋势图）。
- 图表仅作展示，不支持在图上交互修改数据 [交互范围 TBD]。

### 5.5 结果与状态变化

资产总览为只读展示，自身不产生数据变化；页面内容随账户与快照的增删改自动刷新。账单 CSV 导入不影响本页任何数字（资产趋势与收支统计是两套独立计算的结果，见 01 第 5.2、5.3 节）。

### 5.6 字段定义（展示要素）

| 展示要素 | 取值 |
|---|---|
| 总资产 | 见 5.4.1 |

### 5.7 状态

| 状态 | 触发条件 | 界面表现 |
|---|---|---|
| 空态（无账户） | 未创建任何账户 | 初始化引导占位（对应 01 场景 6 完成标志） |
| 空态（有账户、无快照） | 存在使用中账户但无任何快照 | 总资产区显示「录入首次快照」引导，不显示金额；各账户余额显示「—」 |
| 趋势空态 | 快照数不足 2 条 | 见 5.4.3 空数据处理 |
| 数据态 | 至少 1 条快照 | 正常展示总资产、账户结构与最近快照时间 |

### 5.8 异常场景

| 场景 | 产品行为 |
|---|---|
| 无任何账户 | 空态引导 + 「创建第一个账户」入口 |
| 有账户但无快照 | 各账户余额显示「—」，总资产不显示金额（显示引导），不以 0 代替 |
| 仅有 1 条快照 | 趋势图空态引导（见 5.4.3） |
| 全部账户均设为不计入 | 总资产显示 0，并提示「当前没有计入总资产的账户，请检查设置」 |
| 定期账户已到期 | 账户卡片标注「已到期，请确认资金去向」（属提示，不阻塞任何操作） |
