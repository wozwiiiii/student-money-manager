## 1. 模块定位与边界声明（本章为权威声明）

### 1.1 模块定位

本模块是面向理财小白的学习型股票信息模块，向用户提供三项能力，仅此三项：

| 能力 | 内容 |
|---|---|
| 自选股管理 | 用户维护一个自己关注的股票列表（纯"关注"性质，不是持仓） |
| 行情展示与基础分析 | 查看自选股的行情数据与基础指标，每个指标附小白向解释 |
| 学习型内容 | 术语卡片与指标解释，帮助零基础用户看懂行情页面在说什么 |

依据 [01](01-产品定位与整体方案.md) 第 6.1 节模块架构，本模块属于信息消费型扩展，不被任何 P0 模块依赖；缺少本模块不影响"记录—统计—规划"的 P0 闭环成立。

### 1.2 边界声明（不可逾越）

以下三条为模块级硬边界，效力等同于 [01](01-产品定位与整体方案.md) 第 4 章第一性原理约束，任何二期设计不得突破：

| 编号 | 边界 | 可观察的含义 |
|---|---|---|
| B1 | 不提供实盘交易 | 界面上不出现任何买入/卖出按钮、下单入口、跳转券商或交易渠道的链接；不接入用户的真实股票持仓（"无法对接券商实盘交易"为硬约束，见 [01](01-产品定位与整体方案.md) 约束 2） |
| B2 | 不构成投资建议 | 不输出"买入/卖出/持有某股票"类结论，不做个股推荐、买卖点提示、收益预测；全部内容标注教育性定位（见 [01](01-产品定位与整体方案.md) 约束 4） |
| B3 | 不展示买卖操作入口 | 任何页面、卡片、图表、解释文案中均不出现引导交易操作的元素（包括"去开户""立即交易"类跳转） |

[01](01-产品定位与整体方案.md) 第 2.3 节已明确"需要实盘股票交易或个股投资建议的用户"不属于本产品服务对象，本模块设计不向该类期望做任何妥协性让步。

### 1.3 自选股与资产总览的隔离

自选股是"关注列表"，不是资产。本模块与资产汇总模块完全隔离，具体表现为：

- 股票不在 [01](01-产品定位与整体方案.md) 第 5.1 节定义的账户资产类型三选一范围内（现金与活期 / 定期与理财产品 / 基金持仓），本模块不新增资产类型。
- 自选股不计入总资产、不出现在资产快照中、不进入资产趋势图。
- 自选股条目不与任何账户、收支记录、预算周期或储蓄目标发生关联。
- 用户实际持有的股票不在本产品的登记范围内；是否于二期之后扩展资产类型，超出本模块范围，不做预设。

### 1.4 与套件可视化约束的关系（行情走势展示的处理）

套件已限定全局统计类可视化图表为三类：资产趋势图、收支分类占比图、预算进度图。本模块的行情走势展示（如价格走势、K 线、均线叠加）与该约束的关系，本文档给出如下处理：

**处理方式**：行情走势展示定位为"股票模块内部的行情信息呈现形式"，不属于全局统计可视化体系。它仅出现在本模块的个股详情页中，作为行情数据的默认展示方式；不进入资产总览、收支统计、储蓄目标等任何 P0 模块页面，不与三类全局图表并列或混排，也不构成套件的第四类通用图表。

[Assumption, TBD] 上述"模块内信息展示"的定位为推断性决策，需评审确认：评审可维持该定位，也可将其认定为对套件可视化约束的正式扩展（若为后者，须同步修订可视化约束所在的套件文档）。

### 1.5 二期优先级说明

- MVP（P0）不包含本模块，本模块为 P1（二期），与 [01](01-产品定位与整体方案.md) 第 6.3 节分期边界一致；分期理由（依赖方向、数据获取成本、合规成本、验证顺序）见该章，本文档不重复。
- 本文档作为二期规划的输入文档，描述目标形态与开放问题；模块的最终范围以第 5 章数据源调研结论为准 [P1 最终范围裁量 TBD，见 [01](01-产品定位与整体方案.md) 第 6.3 节]。
- 本文档不构成任何实现节奏承诺（见第 5 章措辞说明）。

## 2. 自选股管理

### 2.1 功能目的

让用户维护一个"我在关注哪些股票"的列表，作为本模块全部行情展示与分析内容的唯一作用对象。由于本模块不接入真实持仓（边界 B1），自选股是用户与本模块交互的核心载体。

### 2.2 自选股字段定义

| 字段 | 必填 | 说明 |
|---|---|---|
| 股票代码 | 是 | 股票在所属市场的唯一标识；格式校验规则 [TBD，与数据源支持的市场范围共同确定] |
| 股票名称 | 是 | 添加成功时随代码自动带出，用户不可编辑 [若数据源无法提供名称，展示形态 TBD] |
| 市场 | 是 | 标识股票所属交易市场（如沪市/深市 [具体市场覆盖范围 TBD，依赖数据源]），添加成功时自动带出 |
| 添加时间 | 是 | 系统自动记录用户执行添加操作的时刻，用户不可修改 |
| 备注 | 否 | 自由文本，默认为空；字数上限 [TBD] |

### 2.3 添加自选股

**目的**：将一只用户关注的股票加入自选股列表。

**触发**：用户在自选股列表页点击"添加自选股"入口，弹出添加表单。

**处理规则**：

| 步骤 | 规则 |
|---|---|
| 输入方式 1：代码添加 | 用户输入股票代码，系统校验该代码是否存在 [校验能力依赖数据源 TBD]；存在则带出名称与市场，用户确认后加入 |
| 输入方式 2：名称搜索添加 | 用户输入名称关键词，系统返回候选股票列表（含代码、名称、市场），用户选择其一加入 [搜索能力依赖数据源，能否提供、搜索范围与结果质量均 TBD] |
| 重复判定 | 以股票代码为唯一性判据；市场相同且代码相同视为同一只股票 |
| 上限校验 | 添加前检查当前列表数量是否已达上限（见 2.6） |
| 备注填写 | 添加表单内可选填写备注，也可留待添加后在列表中补充编辑 |

**结果与状态变化**：添加成功后，自选股列表新增一行，展示代码、名称、市场、添加时间与备注；若行情数据可用，该行同时展示行情概要（现价、涨跌幅）[列表是否展示行情概要及其刷新方式依赖数据源 TBD]。

**异常场景**：

| 异常场景 | 产品行为 |
|---|---|
| 代码不存在 | 表单提示"未找到该代码对应的股票"，不加入列表，用户输入保留以便修改 |
| 名称搜索无结果 | 提示"未找到相关股票"，建议改用代码输入 [搜索能力本身是否可用 TBD] |
| 名称搜索返回多个候选 | 展示候选列表供用户自行选择，系统不自动选择 |
| 重复添加（代码已存在） | 提示"该股票已在自选股列表中"，不产生重复条目，列表定位到既有条目 [定位交互形式 TBD] |
| 备注超出字数上限 | 输入时提示上限，超出部分无法继续输入 |
| 行情概要不可用 | 该行仅展示代码、名称、市场、添加时间与备注，行情概要位置展示占位提示（见 3.8） |

### 2.4 自选股列表展示

**目的**：在一个页面集中查看全部自选股及其行情概要。

**布局**：模块内设自选股列表页，为模块默认落地页 [Assumption, TBD]。列表为卡片式条目，每行展示：股票名称、代码、市场标签、现价、涨跌幅（涨跌配色规则 [TBD]）、备注摘要；行情概要区域展示数据时间标记（见 3.5）。点击列表行进入对应股票的个股详情页（见第 3 章）。

**排序规则**：

| 排序方式 | 规则 |
|---|---|
| 默认排序 | 按添加时间倒序，最新添加的排在最前 [Assumption, TBD] |
| 按涨跌幅排序 | 若行情数据可用，支持按涨跌幅排序 [是否提供及排序方向切换 TBD，依赖数据源] |

**结果与状态变化**：进入页面即展示当前列表全部条目；每次添加、删除操作后列表即时更新。列表为空时，页面展示引导占位（说明模块用途与添加入口，并附合规声明，见第 6 章）。

**异常场景**：见 2.3 行情概要不可用条目；列表整体无行情时，所有条目均按无行情形态展示。

### 2.5 删除自选股

**目的**：将不再关注的股票移出列表。

**触发**：用户在列表行的操作入口点击"删除"，弹出确认提示。

**处理规则**：确认后移除该条目；不提供批量删除 [Assumption, TBD]。

**结果与状态变化**：该行从列表中消失，其余条目排序不变；该股票相关的本地展示内容（如备注）随之移除。删除不可撤销；再次关注需重新添加（备注需重填）[是否提供删除后短期恢复能力 TBD]。

**异常场景**：无特殊异常场景；确认提示中的"删除后不可恢复"文案为固定内容。

### 2.6 自选股数量上限

**规则**：自选股数量上限为 20 只 [Assumption, TBD，需评审确认]。

**异常场景**：达到上限后再次添加时，提示已达上限并引导用户先删除不需要的条目；上限不区分市场，全部自选股合并计数。

### 2.7 状态说明

自选股条目无生命周期状态，仅存在"在列表中 / 不在列表中"两种情形。这与 [01](01-产品定位与整体方案.md) 第 5 章各共享概念（如储蓄目标具有进行中/已达成/已放弃状态）不同：自选股是纯关注关系，不承载任何规划或统计语义。

## 3. 行情展示与基础分析

### 3.1 功能目的

在个股详情页集中展示一只自选股的行情数据、基本面指标与技术指标，全部指标附小白向解释（见第 4 章），帮助用户"看懂一只股票的行情页在说什么"，而非"得出买卖结论"。

**布局**：个股详情页从上至下依次为：合规声明条（见第 6 章）、行情概要区（现价/涨跌幅/涨跌额）、基础行情信息区、行情走势区（展示形式见 3.4 与 1.4）、基本面指标区、技术指标区 [各区排序与折叠方式 TBD]。每个指标名称首次出现处附浅白解释（遵循 [01](01-产品定位与整体方案.md) 约束 5：默认一句、点击展开详情 [展开样式 TBD]）。

**触发**：用户在自选股列表点击某一行，进入该股票的个股详情页并加载行情数据。

### 3.2 行情展示内容框架

| 展示项 | 说明 | 数据可用性 |
|---|---|---|
| 现价 | 该股票最新成交价格 | [TBD] |
| 涨跌幅 | 现价相对前一交易日收盘价的变化百分比，正负分别展示 | [TBD] |
| 涨跌额 | 现价减前一交易日收盘价的差值 | [TBD] |
| 开盘价 | 当日第一笔成交的价格 | [TBD] |
| 最高价 | 当日已成交的最高价格 | [TBD] |
| 最低价 | 当日已成交的最低价格 | [TBD] |
| 成交量 | 当日已成交的股票数量 | [TBD] |
| 成交额 | 当日已成交的金额 | [TBD] |
| 其他字段 | 数据源实际可提供的其他行情字段 | [TBD] |

上表为展示框架：具体哪些字段可用、精度与展示单位，全部依赖数据源调研结论，本文档不预设。框架中任一字段不可用时，按 3.8 异常场景处理。

### 3.3 基本面指标清单

每个指标在页面中首次出现的位置附一句浅白解释（解释文案为建议稿，最终文案 [TBD]）：

| 指标 | 小白向解释（建议稿） | 可用性 |
|---|---|---|
| 市盈率（PE） | 股价÷每股收益，可粗略理解为按当前盈利水平多少年回本 | [TBD] |
| 市净率（PB） | 股价÷每股净资产，可粗略理解为按几倍价格买下公司账面净资产 | [TBD] |
| 总市值 | 公司全部股份按当前股价计算的总价值 | [TBD] |
| 股息率 | 一年分红总额÷当前股价，可理解为按当前价格买入、一年分红大约相当于股价的百分之几 | [TBD] |
| 换手率 | 一段时间内成交的股票数量占可流通股票总数的比例，反映交易活跃程度 | [TBD] |

具体哪些指标可提供、口径（静态/滚动等表述差异）依赖数据源 [TBD]；指标区仅做"数值 + 解释"展示，不做任何"高估/低估/便宜/贵"的结论性标注（边界 B2）。

### 3.4 常用技术指标展示框架

| 指标 | 小白向解释（建议稿） | 可用性 |
|---|---|---|
| MA5 | 最近 5 天收盘价的平均值连成的线，反映近一周的平均价格水平 | [TBD] |
| MA10 | 最近 10 天收盘价的平均值连成的线，反映近两周的平均价格水平 | [TBD] |
| MA20 | 最近 20 天收盘价的平均值连成的线，反映近一个月的平均价格水平 | [TBD] |
| 简单趋势描述 | 仅陈述可观察事实的描述（如"最近 20 天的收盘价多数高于 MA20"），不使用"看涨/看跌/金叉/死叉"等方向性判断用语 [表述尺度以评审结论为准] | [TBD] |

均线由行情数据计算得出还是由数据源直接提供 [计算口径 TBD]；除上表所列外不展示其他技术指标（如 MACD、KDJ 等 [是否纳入 TBD，默认不纳入]）。趋势描述的具体措辞以"陈述已发生的价格事实"为限，不得延伸出操作暗示（边界 B2）。

### 3.5 行情数据来源与延迟性

**来源**：[TBD]。二期将调研免费公开行情数据途径（如新浪/腾讯行情接口、开源行情数据源等）的可行性与合规性，调研维度与开放问题见第 5 章，本文档不预设任何结论、不承诺任何具体来源。

**延迟性**：[TBD]。无论调研结论如何，产品行为遵循以下固定规则：

### 3.6 触发与处理规则汇总

| 场景 | 规则 |
|---|---|
| 进入个股详情页 | 加载并展示该股票的行情概要、基础行情信息、走势、基本面与技术指标；各区域独立呈现，任一区域数据不可用不影响其他区域 |
| 行情数据的时间标记 | 每次成功获取数据后更新展示的时间标记 |
| 页面停留期间 | 是否提供手动刷新入口及刷新频率限制 [TBD] |

### 3.7 结果与状态变化

个股详情页的行情数据存在以下可观察状态：

| 状态 | 表现 |
|---|---|
| 已加载 | 各区域展示数据数值，并标注数据时间标记 |
| 数据不可用 | 对应区域展示"数据暂不可用"占位提示，不展示任何占位数值（如 0），并保留最近一次成功数据的时间标记 [占位形态 TBD] |
| 部分字段缺失 | 仅缺失字段不展示并注明"暂无数据"，其余字段正常展示 |

### 3.8 异常场景

| 异常场景 | 产品行为 |
|---|---|
| 行情数据获取失败 | 行情区域进入"数据暂不可用"状态（见 3.7），自选股基础信息（代码/名称/市场/备注）不受影响 |
| 股票停牌 | 停牌期间行情数据如何呈现 [TBD，含是否展示停牌状态说明] |
| 数据源整体不可用 | 全部自选股行情进入不可用状态，模块顶部展示说明条；自选股管理功能（添加/删除/备注）不受行情不可用影响 |
| 指标数值异常（如为负或缺失） | 按"部分字段缺失"处理，不做推测性填充 |

## 4. 学习型分析视角

### 4.1 功能目的

面向零基础用户（[01](01-产品定位与整体方案.md) 第 2.1 节主画像："基本不用行情与分析功能"）组织本模块的全部内容：让用户在看行情的过程中顺便学会看懂行情，而不是先学习再使用。

### 4.2 内容组织方式

| 组织方式 | 说明 |
|---|---|
| 指标解释 | 第 3 章每个指标在页面首次出现处附一句浅白解释，点击展开更详细说明 [展开样式 TBD]（遵循 [01](01-产品定位与整体方案.md) 约束 5） |
| 术语卡片 | 模块内提供股票常用术语的浅白解释卡片，解释以"说明这个词是什么"为限 |

### 4.3 术语卡片清单（建议稿）

| 术语 | 浅白解释（建议稿） |
|---|---|
| K 线 | 用一根柱子同时展示某段时间（通常是一天）内开盘价、收盘价、最高价、最低价四个价格的图形，柱子的颜色区分收盘价高于还是低于开盘价 |
| 成交量 | 一段时间内买卖双方成交的股票数量，反映交易的热闹程度 |
| 多头与空头 | 多头指预期价格会涨的人，空头指预期价格会跌的人；"多头市场"通常指价格持续上涨的行情 |
| 开盘价 / 收盘价 | 当日第一笔成交的价格 / 当日最后一笔成交的价格 |
| 涨跌幅 | 现价相对前一交易日收盘价的变化百分比 |
| 停牌 | 股票因故暂停交易，期间无法买卖 |

术语卡片完整清单与最终文案 [TBD]；卡片内容为教育性信息，不含任何操作指引。

### 4.4 触发与展示规则

| 触发 | 规则 |
|---|---|
| 指标解释 | 随指标展示位置内联出现，无需用户主动查找 |
| 术语卡片 | 在个股详情页内被解释术语的可点击入口进入 [卡片入口与组织形式 TBD] |
| 首次进入模块 | 首次进入时显著展示合规声明（见第 6 章），并可选择查看"新手怎么看行情页"的入门说明 [是否提供该入门说明 TBD] |

### 4.5 明确不做（负面清单）

以下功能类型一律不提供，作为内容边界 B2 的具体化：

| 不做的功能 | 原因 |
|---|---|
| 个股推荐、股票排行榜（涨幅榜、人气榜等） | 构成投资建议与引导（边界 B2） |
| 买卖点提示、任何技术信号的操作化解读 | 构成投资建议（边界 B2） |
| 收益预测、目标价 | 构成投资建议（边界 B2） |
| 自选股之间的收益 PK、对比排名等引导性功能 | 引导比较与追逐收益（边界 B2） |
| 实盘持仓展示与任何买卖操作入口 | 边界 B1、B3 |
| 社区讨论、跟单类功能 | 引导性功能，且超出信息层定位 |

## 5. 数据源调研要求（二期启动条件）

**措辞说明**：本章为产品依赖声明——本模块进入实现阶段前，下列开放问题需有明确结论；本章不构成任何排期、里程碑或实现节奏承诺。所有问题均为开放问题，本文档不预设答案。

### 5.1 调研项（开放问题清单）

| 编号 | 调研维度 | 待回答的开放问题 |
|---|---|---|
| R1 | 接口可用性 | 哪些免费公开行情途径可用（如新浪/腾讯行情接口、开源行情数据源等）？各自覆盖哪些市场？各自可提供第 3.2～3.4 章所列哪些字段？是否支持按名称搜索股票？ |
| R2 | 数据延迟 | 各途径的行情数据延迟是多少？该延迟以明确标注的方式展示，对目标用户是否可接受？ |
| R3 | 使用合规性 | 各途径的服务条款是否允许第三方应用展示其数据？是否需要授权、署名或其他义务？是否存在法律或条款风险？ |
| R4 | 稳定性 | 各途径的长期稳定性如何？是否有使用频率限制？失效风险与历史表现如何？ |
| R5 | 兜底方案 | 若主要途径失效，是否存在可替换的备选途径？无任何可用途径时，本模块的降级形态是什么（如仅保留自选股管理）？ |
| R6 | 名称搜索 | 基于以上结论，2.3 节的名称搜索添加方式是否可行？不可行时是否仅保留代码添加？ |
| R7 | 走势展示 | 基于以上结论，3.4 节的技术指标与行情走势展示可支撑到什么程度？ |

### 5.2 决策点

上述调研结论将直接决定以下决策（均不预设）：

| 编号 | 决策点 |
|---|---|
| D1 | 本模块是否按本文档所述范围进入实现，或缩小（如仅自选股 + 现价/涨跌幅），或调整后实现 |
| D2 | 第 2～3 章全部 [TBD] 字段的最终清单与形态 |
| D3 | 2.6 节自选股上限等 [Assumption, TBD] 项的最终取值 |
| D4 | 1.4 节行情走势展示与套件可视化约束关系的评审结论 |

### 6.1 固定免责文案（完整建议稿）

以下文案为模块入口固定展示的免责声明建议稿，最终文案以评审与合规审查结论为准 [TBD]：

> **风险提示与免责声明**
>
> 行情信息仅供参考，不构成投资建议；股市有风险，入市需谨慎。
>
> 本模块为学习型信息展示：所有行情数据与指标可能存在延迟或误差，请以交易所官方披露信息为准。本产品不提供股票交易功能，不推荐任何具体股票，不提示任何买卖时机，页面中不出现任何买卖操作入口。本模块全部内容（行情、指标、解释、术语卡片）均为教育性信息。

| 时机 | 展示方式 |

本模块的合规声明是 [01](01-产品定位与整体方案.md) 约束 4 所述"教育性信息，不构成投资建议"统一声明体系在股票模块的实例化：文案语义与套件其他投资相关内容（配置教育、银行产品信息库）保持一致，不与本模块内其他文案冲突；模块内任何新增文案（术语卡片、指标解释、异常提示）均不得包含与 6.1 声明相抵触的表述。
